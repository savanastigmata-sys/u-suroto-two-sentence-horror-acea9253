A two-sentence horror story for make.fun's "Two-Sentence Horror" bounty. The program writes one original horror story of exactly two sentences (195 characters) to `entry.txt`: a quiet, implied dread — a rescued dog that flinches at raised voices finally speaks, in the narrator's own voice, saying words the narrator only thought.

## Run it

```sh
python3 main.py
```

The story is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is not set). The program validates the story first: 1–400 characters, not only white space, exactly two sentences.
